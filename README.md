# Plataforma de Accionistas CONSA

Copia de la Plataforma de Accionistas IVELSA v1.2.1 (repo `Portal-Accionario`), con marca, logo y colores de CONSA (Consorcio Salinero del Tarapacá S.A.).

- URL: https://socialis.consorciosalinero.cl
- Requisitos: PHP 8.x con pdo_mysql, gd y zip; MySQL 5.7+/8 o MariaDB 10.4+ (SiteGround).

## Instalación en SiteGround

1. Crear el subdominio `socialis.consorciosalinero.cl` y activar SSL.
2. Crear una base de datos MySQL y su usuario.
3. Subir el contenido de `socialis-consa-v1.2.1.zip` a la carpeta pública del subdominio y descomprimir.
4. Abrir https://socialis.consorciosalinero.cl/install.php, ingresar los datos de la base y presionar «Instalar».
5. Eliminar `install.php` desde el Administrador de archivos.

## Acceso inicial

- Correo: master@consa.cl
- Clave inicial: entregada por separado (la muestra install.php al terminar). Cámbiela en el primer ingreso.
